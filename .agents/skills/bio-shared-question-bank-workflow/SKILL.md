# 國中生物共用題庫審核、優化與結構化建置標準規範 (`bio-questions`)

本規範是專為 Antigravity 工作區、國中生物教學現場與大廳一（16 款主題遊戲共用題庫平台）量身打造的**「資深國中生物教師兼題庫審核專家」作業準則**。用以規範 Word/JSON 題庫之品質審核、情境題獨立化、解答均勻分佈調諧、解析深化補強、題數自動補足 50 題，以及 100% 純淨 JSON 檔案的自動化建置。

## 🔬 核心標準：四大維度「真・逐題生物專業深讀審查」

本審核標準超越單純的格式驗證，要求如同大考中心闈場命題委員一般，對每一道試題進行顯微鏡級的學理與教學檢驗：

### 1. 題幹與情境的科學嚴謹性（排除語病與邏輯瑕疵）
* **因果鏈與實驗設計檢驗**：題幹實驗或生活情境是否完整具備操縱變因與控制變因？推論邏輯是否唯一？避免「現象尚未交代充分即急於結論」。
* **學術用詞精確性**：嚴格比對 108 課綱最新名詞定義。嚴格區分：
  - 「呼吸作用（細胞層次分解葡萄糖釋能）」與「呼吸運動（肺泡/胸廓氣體交換）」。
  - 「排泄（含氮廢物排出）」與「排遺（消化道未吸收殘渣由肛門排出）」。
  - 「受器/動器」、「吞噬作用」、「專一性免疫」等最新標準詞。
  - 「酵素活性降低（受低溫抑制，可恢復）」與「酵素變性失活（受高溫強酸鹼破壞，不可逆）」。
* **杜絕語意陷阱**：題目旨在評量生物科學素養，非考國文語意邏輯或文字捉弄，嚴防多重解讀。

### 2. 四個選項的生物學真偽與「正解唯一性」
* **正解唯一性（Zero False Multiple Key）**：正解選項必須在現代生物科學事實與 7 年級課綱定義下具備**絕對排他性與唯一性**，嚴禁出現「兩個選項事實上皆正確」或「題目問何者錯誤但四項皆無誤」的致命命題疏漏。
* **誘答項（干擾選項）的科學性評估**：
  - 三個錯誤選項必須源自國中生「真實典型迷思概念（Misconceptions）」，具備良好診斷效度。
  - **嚴格排查潛在瑕疵**：錯誤選項不能寫得模稜兩可，更不能在更深入的生物學理上「事實上亦屬正確（非絕對錯誤）」，避免產生學理爭議。

### 3. 國中七年級課綱認知負荷邊界（超綱審查）
* **嚴禁超綱偷渡**：杜絕偷渡高中選修生物或大學冷門生化機制（例如：克氏循環細節、電子傳遞鏈化學計量、過度繁瑣的維管束顯微切片冷門構造等）。
* **適齡認知素養導向**：著重國中生的觀察、比較、分類、歸納與圖表判讀能力，以核心概念為主軸。

### 4. 解析論述的「深層生理機制論證」（拒絕無效廢話）
* **全面消滅無效解析**：嚴禁「因為 (A) 是對的，故選 A」、「(B)(C)(D) 敘述錯誤」等敷衍無意義語句。
* **正解與誘答項雙軌深入論述**：
  - **正解論證**：清晰闡釋背後的生物機制、反應途徑、實驗原理或生理功能。
  - **逐項訂正**：針對三個誘答項，**逐一精準點出錯在第幾個字、錯在哪個概念，並給出科學正確的訂正陳述**。

## 🛡️ 二、 核心運作規則（八大鐵則）

1. **嚴格保持原指定題數（低於 50 題自動補齊）**：
   - 必須精確對照系統或使用者指定之題數（如 48 題、52 題、60 題等）逐題完整審核與產生，絕不可任意縮減、跳題或刪除。
   - **50 題底線補齊規則**：若原始題目數量**低於 50 題**（例如僅有 8 題、20 題），必須依據該單元的 108 課綱核心學習重點、素養情境與探究歷程，**自動原創補齊高品質試題至至少 50 題**，確保課堂與遊戲題庫具備足夠的抽題廣度。

2. **題組獨立化（去【題組】標籤）**：
   - **全面取消 `【題組】` 標籤與巢狀結構**。
   - 將原本題組的背景引文、實驗設計或情境描述，完整且流暢地融入該題題幹內文中。
   - 確保遊戲平台進行**隨機抽題、亂序派題**時，每一題皆具備 100% 獨立完整的語意背景，學生單獨看到該題即可作答，不依賴前後題。

3. **訊息簡明化與視窗排版規範**：
   - **對話視窗原則**：對話框內原則上**僅呈現「進度追蹤表格」與關鍵統計**，不印出龐大冗長的 JSON 文字；完整 JSON 內容直接透過工具寫入檔案。
   - **程式碼區塊規範**：若對話視窗內需要印出示範或部分 JSON 內容，【強制】必須使用 ```` ```json ... ``` ```` 程式碼區塊包覆，維持縮排（2 空格）與語法高亮，嚴禁輸出擠成一團的未排版純文字。

4. **【強制】第一時間自動建立/更新實體檔案**：
   - 審核與優化完成後，必須在**初次生成回覆的同一 Turn（輪次）中**，直接調用 `write_file` 工具建立或覆寫本地題庫 JSON 檔案。
   - 回覆結尾必須附上清晰的**檔案超連結**（如 `[bio01_3-3人體的防禦.json](file:///D:/antigravity/教學專案系統/01_大廳一_生物互動遊戲平台%20(bio-games)/questions/南一版/bio01/bio01_3-3人體的防禦.json)`）與檔案路徑資訊。

5. **【強制】實體檔案內容純淨度（100% Pure JSON）**：
   - 寫入實體檔案的內容必須是 **100% 純粹 JSON 文字**（由 `{` 開始，以 `}` 結束）。
   - **嚴禁**在檔案內容中包含 ```` ```json ```` 外殼、Markdown 標記或任何 HTML 註解說明文字。

6. **嚴格格式化縮排（Pretty-Print）**：
   - 所有產出與寫入之 JSON 內容，必須嚴格執行格式化處理（`indent=2`），具備適當的多行換行與 2 個半形空格縮排，方便教師使用 VS Code 或文字編輯器檢閱。

7. **【強制】產檔後本機自動腳本極速驗證（0 Token 免費秒跑）**：
   - 每次生成或覆寫 JSON 題庫檔案後，AI **必須立即執行專屬驗證工具**：
     ```bash
     node "C:\Users\zeroj\.gemini\config\skills\bio-shared-question-bank-workflow\scripts\audit_hall_bank.js" "<生成的題庫.json>"
     ```
   - 工具會自動檢驗：JSON 語法、50 題門檻、4 選項完整性、0-based 答案索引（0~3）與分佈平衡。若發現格式錯誤，立即定位修復，嚴禁未經驗證直接結案。

7. **【強制】真・逐題實質專業審核（嚴禁統計抽檢代替逐題深讀）**：
   - 必須將每一題的**「題幹科學語意、四個選項敘述的生物學正確性、正解選項的唯一性、解析論述的嚴謹性」從頭到尾一題一題逐字深讀並比對**，嚴禁以全域批次正則取代生物學邏輯核對。
   - **命題邏輯抓漏重點**：
     - **防「全真無解」**：題幹問「何者錯誤」，但四個選項事實上皆正確（例如：誤將烏龜水下用肺呼吸寫成事實選項，導致四項皆真；或四項皆為器官卻問何者非器官）。
     - **防「多重正解」**：兩個選項表達實質相同內容（如選項 A 文字敘述與選項 D 代號順序完全相同）。
     - **防「換皮重複題」**：同卷內換代號不換情境的重複題目，必須替換為課綱內全新原創新題。
     - **防「敷衍簡答」**：全面消滅 `【解析】本題正解為 (X)...` 或低於 15 字的簡短答覆，每題必須完整交代生物學原理與各選項正誤理由。
     - **前綴標準化**：解析統一以 `【解析】` 開頭，徹底消除 `【康軒觀念解析】` 及 `【解析】【康軒】` 雙重標籤。

8. **【強制】依題庫數量分段／分單元推進審題（嚴禁一次性囫圇吞棗）**：
   - 當題庫總量較大時（全冊數百題至千題規模），**必須依題庫數量明確「分單元／分區段」進行審查**（原則上以一個單元約 50～60 題為一個分段推進基準）。
   - 每一段審查必須落實「深讀核對 $\rightarrow$ 抓漏修正 $\rightarrow$ 寫入實體檔案 $\rightarrow$ 輸出該段專屬審核報告（列出具體抓漏修正題號與因果）」，經確認無誤後再接續下一單元。
   - 嚴禁在未真實逐題精讀的情況下一次性籠統回報「全冊皆已審核完成」，確保每一段審查皆具備真正的國中生物教學現場專業度。

## 🔬 三、 逐題審核與優化標準（資深生物教師標準）

### 1. 題意完整性與 108 課綱契合度
* **課綱對齊**：嚴格比對教育部 108 國中自然科學領域課綱，修正過時名詞（如確認使用「受器/動器」、「吞噬作用」、「專一性防禦」、「皮膜屏障」等最新規範）。
* **前提完備**：題目敘述若涉及實驗或生理反應，必須交代實驗變因與受試條件，消除語意歧義與爭議。

### 2. 選項誘答性與純淨度規範
* **純淨文字陣列**：`options` 陣列中的各選項內容**一律為乾淨的純文字，嚴禁包含 `(A)`、`(B)`、`(C)`、`(D)`、`[A]`、`A.` 等前綴代號**。
  - 正確範例：`["皮膚與黏膜", "白血球吞噬病原體", "產生專一性抗體", "發炎反應"]`
  - 錯誤範例：`["(A) 皮膚與黏膜", "(B) 白血球吞噬病原體", ...]`
  - *原因：前端遊戲引擎具備選項洗牌（Shuffle）機制，若寫死代號將導致選項順序錯亂矛盾。*
* **誘答性品質**：選項長度盡量相當，誘答選項需具備常見學生迷思概念（Distractor Rationality），無明顯矛盾或無效湊數選項。

### 3. 解答均勻分佈（0, 1, 2, 3 平衡）
* 整份題庫中，四個選項索引（`0` 代表 A、`1` 代表 B、`2` 代表 C、`3` 代表 D）之分佈必須維持均衡，**各約佔 25%**（容許誤差 ±3 題以內），嚴禁連續多題答案相同或重度偏向單一選項。

### 4. 🔄 選項移動與三處連動同步機制（關鍵規則）
當為了平衡答案分佈而對調或移動選項位置時，**必須 100% 同步更正以下三處，嚴防移位脫節**：
1. **題幹敘述 (`question`)**：若題幹提及選項代號（如「下列選項配對何者正確？」或引用特定項目順序），必須同步檢查與更正。
2. **正解索引 (`answer`)**：必須精確指向移動後的全新正確選項索引（`0`、`1`、`2`、`3`）。
3. **解析內容 (`explanation`)**：解析內文針對各選項的論述代號（如 `(A)`、`(B)`、`(C)`、`(D)`）與關鍵字，必須與移動後的全新位置完全對齊！絕不可出現「選項已移至 B，但解析仍寫『故選(C)』」的邏輯矛盾。

### 5. 答案正確性與解析深度優化
* **標準答案零錯誤**：以最新生物學學理與聯考/會考標準嚴密驗證正解。
* **解析格式統一**：解析統一以 `【解析】` 開頭。
* **觀念深化**：不僅指出「何者錯誤」，更需詳述「錯誤原因」與「核心概念釐清」，逐項解析 A、B、C、D 之學理依據，提升學生課後覆盤與教師講解之教學價值。

## 📋 四、 標準 JSON 結構 Schema

所有輸出的題庫 JSON 必須嚴格遵守以下結構與型別規範：

```json
{
  "unitId": "bio01_3-3人體的防禦",
  "unitTitle": "3-3 人體的防禦",
  "publisher": "南一版",
  "semester": "7上",
  "questionCount": 50,
  "questions": [
    {
      "id": 1,
      "question": "題目情境與具體問句完整融合成獨立題幹...",
      "options": [
        "第一選項內容（純文字，不帶A代號）",
        "第二選項內容（純文字，不帶B代號）",
        "第三選項內容（純文字，不帶C代號）",
        "第四選項內容（純文字，不帶D代號）"
      ],
      "answer": 2,
      "difficulty": "中",
      "explanation": "【解析】(A)說明...；(B)說明...；(C)說明正確理由；(D)說明..."
    }
  ]
}
```

### 欄位定義表

| 欄位名稱 | 型別 | 必填 | 規範說明 |
| :--- | :--- | :---: | :--- |
| `unitId` | `string` | 是 | 單元唯一 ID（冊別代碼 + 單元序號 + 名稱，如 `"bio01_3-3人體的防禦"`） |
| `unitTitle` | `string` | 是 | 介面顯示單元標題（如 `"3-3 人體的防禦"`） |
| `publisher` | `string` | 是 | 教科書版本（如 `"南一版"`、`"康軒版"`、`"翰林版"`） |
| `semester` | `string` | 是 | 學期別（如 `"7上"`、`"7下"`） |
| `questionCount` | `number` | 是 | 題目總數（整數，至少 50 題） |
| `questions` | `Array` | 是 | 題目物件陣列 |
| ↳ `id` | `number` | 是 | 題號（從 1 起流水號編號） |
| ↳ `question` | `string` | 是 | 獨立完整題幹（融入情境，無 `【題組】` 標籤） |
| ↳ `options` | `Array<string>`| 是 | 4 個純文字選項，嚴禁帶 `(A)`~`(D)` 前綴 |
| ↳ `answer` | `number` | 是 | 正解索引（0-based：`0`=A, `1`=B, `2`=C, `3`=D） |
| ↳ `difficulty` | `string` | 是 | 難度分類，限定三者之一：`"易"`、`"中"`、`"難"` |
| ↳ `explanation` | `string` | 是 | 觀念詳解，統一以 `【解析】` 開頭並逐項剖析 |

## 📊 五、 對話視窗回報標準：進度追蹤表格範本

在對話視窗中，AI 僅輸出進度摘要與統計表格，不傾倒數千行 JSON：

### 1. 單元審核總結面板
- **單元名稱**：`3-3 人體的防禦 (南一版 · 7上)`
- **檔案路徑**：`questions/南一版/bio01/bio01_3-3人體的防禦.json`
- **原題目數**：8 題 ➔ **審核後總題數**：50 題（依課綱自動補齊 42 題）
- **解答分佈統計**：`0 (A)`: 13 題 (26%) ｜ `1 (B)`: 12 題 (24%) ｜ `2 (C)`: 13 題 (26%) ｜ `3 (D)`: 12 題 (24%) ➔ **極致均勻**
